# XY mega evolution assets

Pokémon artwork and item sprites from the PokeAPI sprites repository, downloaded
with `node scripts/import-xy-mega.mjs`. Characters belong to Pokémon/Nintendo,
Game Freak and Creatures. https://github.com/PokeAPI/sprites

The importer also snapshots Generation VI base stats (including historical stat
changes), item inventory indices and Spanish/English stone names from PokéAPI.
The screen needs no external requests after the app assets load.

The form list is restricted to released XY mega forms (28, including event Blaziken).
ORAS forms and unreleased XY Latias/Latios stones are excluded. Both X/Y variants
are supported in either version because stones can be traded.
XY reference: https://assets.pokemon.com/assets/cms2-en-uk/pdf/video-game/pokemon-xy/MegaStoneGuide_LowRez.pdf
